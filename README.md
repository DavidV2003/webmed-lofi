# Webmed Healthcare - Prototipo Hifi

Este proyecto corresponde a un prototipo de alta fidelidad para el sistema Webmed Healthcare.

## Objetivo

Representar de forma visual e interactiva las pantallas principales del sistema, permitiendo validar la navegación, la organización de la información y el flujo de uso de los servicios principales de la plataforma.

## Descripción del proyecto

Webmed Healthcare es una propuesta de sistema web orientada a facilitar el acceso a servicios de salud. El prototipo permite simular la interacción de un usuario con diferentes módulos, como búsqueda de doctores, compra de medicamentos, consulta de seguros médicos, solicitud de ambulancia, recursos de salud y notificaciones.

Este prototipo no corresponde a una aplicación final con backend real, pero sí permite visualizar de manera más cercana cómo podría funcionar la interfaz del sistema.

## Pantallas incluidas

- Inicio de sesión
- Panel principal
- Búsqueda de doctores
- Compra de medicamentos
- Carrito y pago
- Confirmación de pedido
- Seguros médicos
- Solicitud de ambulancia
- Noticias y recursos de salud
- Notificaciones

## Funcionalidades simuladas

- Inicio de sesión básico
- Navegación entre pantallas
- Búsqueda de doctores por especialidad o ciudad
- Visualización de información básica de médicos
- Búsqueda de medicamentos por nombre o categoría
- Agregar medicamentos al carrito
- Modificar cantidades en el carrito
- Eliminar productos del carrito
- Calcular el total del pedido
- Seleccionar método de pago
- Registrar dirección de entrega
- Confirmar pago
- Generar número de orden
- Simular confirmación de cita médica

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- GitHub Pages
