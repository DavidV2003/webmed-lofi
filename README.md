# Webmed Healthcare - Prototipo Lofi

Este proyecto corresponde a un prototipo de baja fidelidad para el sistema Webmed Healthcare.

## Objetivo

Representar de forma sencilla las pantallas principales del sistema, permitiendo validar la navegación, la organización de la información y el flujo básico de compra de medicamentos.

## Pantallas incluidas

- Inicio de sesión
- Panel principal
- Búsqueda de doctores
- Compra de medicamentos
- Carrito y pago
- Confirmación de pedido
- Seguros médicos
- Solicitud de ambulancia
- Noticias y recursos
- Notificaciones

## Funcionalidades simuladas

- Inicio de sesión básico
- Navegación entre pantallas
- Búsqueda de doctores
- Búsqueda de medicamentos
- Agregar productos al carrito
- Modificar cantidades
- Calcular total
- Confirmar pago
- Generar número de orden

## Cómo ejecutarlo

Abrir el archivo `index.html` en el navegador.

## Nota

Este prototipo no incluye backend, base de datos ni integraciones reales. Su propósito es representar una propuesta inicial de interfaz y flujo de navegación.
